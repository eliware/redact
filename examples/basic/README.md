# Basic example

[Back to the examples](../README.md) · [Project README](../../README.md)

## Prerequisites

Use Node.js 26 or newer and run `npm install` from the repository root.

From the repository root, run:

```sh
node examples/basic/index.mjs
```

The example uses placeholder values only.

## Expected results

The command prints redacted text and serialized objects. Placeholder tokens
such as `example-token` and `example-password` are never real credentials.
